Pasta das planilhas Excel

No Chrome ou Edge do computador, escolha uma pasta uma única vez. A cada salvamento o sistema atualiza Controle_EPI_<Mês>.xlsx e CONTROLE_ESTOQUE_EPI.xlsx dentro dela. Um arquivo novo só é criado quando o mês muda. Em outros navegadores (ou no celular), a planilha do mês é baixada a cada salvamento.

Backup dos dados

Os lançamentos ficam guardados neste navegador, neste computador. Faça backup com frequência e use "Restaurar" para levar os dados para outro computador. Limpar os dados do navegador apaga os lançamentos.
